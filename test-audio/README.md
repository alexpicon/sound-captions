# Audio data and annotations

The repository includes annotation CSVs, two demo speech-subtitle SRTs, the frozen YAMNet encoder, and its class map. Raw audio and video are excluded from Git.

| Directory | Contents |
| --- | --- |
| `real-clips/` | Annotations for the original Twitch clips and later skirmish recordings; source links are in its README |
| `clips/` | Labels for synthetic Xonotic development and test mixes; recordings are not bundled |
| `model/` | The bundled YAMNet TFLite encoder and AudioSet class map |
| `xonotic-sounds/` | GPLv3 license text for the historical Xonotic sound sources; sound files are not bundled |

## Data roles

[`splits.json`](../splits.json) is the authoritative split manifest. The submitted evaluation uses four held-out Valorant clips, while training and model selection use separate development clips. Counter-Strike and synthetic Xonotic results are outside the selected submission comparison. See the [results guide](../docs/RESULTS.md).

CSV columns are `start_s,end_s,label,direction`. Game sounds use `footsteps`, `gunshot`, `reload`, and `explosion`; `talking` and `music` mark context. Directions are `left`, `right`, and `center`. A missing label is not proof of silence unless the entire clip was reviewed.

Place your own recordings next to their annotations for replay or restore the original filenames from the split manifest to reproduce the corpus. The live helper can also analyze an arbitrary stereo recording without annotations.
